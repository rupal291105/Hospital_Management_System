5. JOIN Operation

Patient + Doctor + Appointment data using INNER JOIN.

Patient Doctor Appointment Date Status
SELECT p.name AS patient, d.name AS doctor, a.appointment_date, a.status FROM appointments a JOIN patients p ON a.patient_id = p.id JOIN doctors d ON a.doctor_id = d.id;

6. GROUP BY + Aggregate

Appointments by Status

Status Total Appointments
