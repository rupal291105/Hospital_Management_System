# Hospital Management System

A Java and MySQL based Hospital Management System developed using JDBC. The system manages patients, doctors, appointments and bills through a console-based interface.

## Technologies Used

- Java
- MySQL
- JDBC
- MySQL Connector/J
- GitHub

## Features

- Add Patient
- View Patients
- Update Patient
- Delete Patient
- Add Doctor
- View Doctors
- Book Appointment
- View Appointments
- Generate Bill
- View Bills
- MySQL database connectivity
- CRUD operations
- JOIN operations
- Database trigger / logging

## Database Tables

The project uses the following tables:

- `patients`
- `doctors`
- `appointments`
- `bills`
- `patient_log`
